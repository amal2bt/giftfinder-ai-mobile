# 🎁 GiftFinder AI — Mobile App

A cross-platform mobile application built with **React Native** and **Expo** that delivers personalized, AI-powered gift recommendations, end-to-end gift delivery ordering, and smart occasion reminders tailored to recipients, interests, and budgets.

## ✨ Features
- **AI Gift Recommendations:** Smart gift discovery engine generating tailored gift ideas based on recipient profile, occasion, and budget preferences.
- **Integrated Gift Delivery System:** Seamless in-app gift ordering and delivery scheduling with real-time order status tracking straight to the recipient.
- **AI & Custom User Reminders:** Automated AI-generated occasion alerts alongside custom user-created reminders for birthdays, anniversaries, and special events so no milestone is missed.
- **Recipient & Wishlist Management:** Save favorite gift ideas, organize gift lists for upcoming events, and track past selections.
- **Real-Time Ecosystem Sync:** Seamlessly connected to the GiftFinder AI backend API and admin control panel for live catalog updates, order fulfillment, and user data synchronization.
- **Cross-Platform Mobile UX:** Smooth navigation powered by Expo file-based routing (`app/`), responsive layouts, and native mobile interactions for iOS and Android[cite: 5].

## 🛠️ Tech Stack
- **Framework:** React Native, Expo, TypeScript[cite: 5]
- **Routing & State:** Expo Router (file-based routing), Context API & Store architecture[cite: 5]
- **Backend & Database:** RESTful API integration, Supabase (PostgreSQL)
