# 🎁 GiftFinder AI — Mobile App

A cross-platform mobile application built with **React Native** and **Expo** that delivers personalized, AI-powered gift recommendations tailored to recipients, occasions, interests, and budgets.

## ✨ Features
- **AI Gift Recommendations:** Smart gift discovery engine generating tailored gift ideas based on recipient profile, occasion, and budget preferences.
- **Recipient & Wishlist Management:** Save favorite gift ideas, organize gift lists for upcoming events, and track past selections.
- **Real-Time Ecosystem Sync:** Seamlessly connected to the GiftFinder AI backend API and admin control panel for live catalog updates and user data synchronization.
- **Cross-Platform Mobile UX:** Smooth navigation powered by Expo file-based routing (`app/`), responsive layouts, and native mobile interactions for iOS and Android.

## 🛠️ Tech Stack
- **Framework:** React Native, Expo, TypeScript
- **Routing & State:** Expo Router (file-based routing), Context API & Store architecture[cite: 5]
- **Backend & Database:** RESTful API integration, Supabase (PostgreSQL)
